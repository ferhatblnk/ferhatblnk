## About

Full stack developer focused on **backend architecture** and **API-driven systems**. I build
multi-tenant SaaS platforms end to end — from PostgreSQL schema design and .NET service layers
to the Angular / React / Flutter clients that consume them.

- Designing and shipping **ASP.NET Core** services with Clean Architecture and layered domain boundaries
- Building **REST / real-time APIs**, background job pipelines and third-party integrations
- **Relational data modeling** and query performance work on PostgreSQL, MSSQL and MySQL
- Cross-platform product delivery with **Angular**, **React** and **Flutter**
- Currently studying applied **machine learning** and neural networks with Python
